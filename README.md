Разработал тесты для REST API сервиса, возвращающего список кафе по заданным параметрам (город и количество кафе), в рамках проектной деятельности на языке Go. Проект относится к сфере веб-разработки и тестирования API, с целью проверки корректности обработки запросов и обработки ошибок. Использовались технологии: Go, фреймворк testify (пакеты assert и require), стандартный пакет net/http/httptest для создания тестовых серверов. Пользователи — разработчики, использующие API для получения данных о кафе (например, для приложений в сфере общепита).
